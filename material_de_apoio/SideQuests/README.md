# 🧭 SideQuests — Redes de Computadores

Esta pasta contém **SideQuests**, que são atividades práticas complementares à disciplina de **Redes de Computadores**.

Os SideQuests **não fazem parte do conteúdo central da ementa**, mas utilizam conceitos de redes para criar aplicações interessantes, exploratórias e motivadoras, aproximando o aluno de problemas reais e de cenários mais avançados.

---

## 🎯 O que são SideQuests?

O termo *SideQuest* é inspirado em jogos digitais e representa:

- Atividades paralelas ao conteúdo principal;
- Exercícios exploratórios e experimentais;
- Problemas abertos, com múltiplas soluções possíveis;
- Uso prático de conceitos de redes, programação e sistemas.

Os SideQuests permitem que o aluno:
- Experimente conceitos além do básico;
- Desenvolva autonomia;
- Conecte redes com outras áreas (automação, jogos, sistemas distribuídos, monitoramento, etc.).

---

## 🧠 Conceitos de Redes Trabalhados

Dependendo do SideQuest, podem ser abordados:

- Sockets TCP e UDP
- Broadcast e descoberta de serviços
- Comunicação cliente/servidor
- Threads e concorrência
- Monitoramento de dispositivos
- Protocolos simples de aplicação
- Controle remoto e automação
- Integração entre redes e aplicações gráficas
- Coleta de dados de sensores e visualização local

> ⚠️ **Observação:** cada SideQuest possui seu próprio `README.md` explicando os conceitos específicos utilizados.

---

## 📁 Organização da Pasta

Cada subpasta dentro de `SideQuests` representa um **desafio independente**, contendo:

- Código-fonte (normalmente em Python);
- Um `README.md` próprio com:
  - Objetivo do SideQuest;
  - Explicação do funcionamento;
  - Instruções de execução;
  - Conceitos abordados.

## 🚀 Como usar os SideQuests

1. Escolha um SideQuest de interesse;
2. Leia atentamente o `README.md` da subpasta;
3. Execute os exemplos localmente;
4. Modifique o código, experimente variações e extensões;
5. Utilize como base para trabalhos, estudos ou desafios extras.

Os SideQuests podem ser usados:
- Em sala de aula;
- Como atividade extra;
- Como base para projetos maiores;
- Como inspiração para trabalhos avaliativos.

---

## 🧪 Nível de Complexidade

Os SideQuests **variam de dificuldade**, indo desde exemplos simples até aplicações mais elaboradas.  
Eles assumem que o aluno já tenha conhecimentos básicos de:

- Programação (Python ou equivalente);
- Conceitos fundamentais de redes;
- Uso de terminal e sistema operacional.

---

## 📌 Observações Importantes

- Os códigos têm **foco didático**, não produtivo;
- Nem sempre seguem padrões industriais completos;
- O objetivo é **aprender**, testar e explorar;
- O aluno é incentivado a quebrar, modificar e estender o código.
